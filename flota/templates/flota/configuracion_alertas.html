⏰ Automatización en PythonAnywhere

Para que el sistema revise y envíe las alertas todos los días automáticamente sin que nadie tenga que entrar a la web:

  1. Entra a la pestaña Tasks de tu cuenta de PythonAnywhere.
  2. Crea una nueva Scheduled Task (ej: a las 08:00 UTC o según convenga).
  3. Ingresa el siguiente comando:
    cd ~/Coalfa && python manage.py enviar_alertas_flota
  4. ¡Listo! El comando evaluará la lista de correos guardados y enviará el correo consolidado solo si hay vencimientos o mantenciones pertinentes.
